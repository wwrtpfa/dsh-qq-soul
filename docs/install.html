! 动手之前，先确认 3 件事

① 机器人号必须是小号主号拿去当机器人，你自己就没法正常用了。
② 别装上游 Aurabot两者挂载 ID、配置目录完全相同，会撞车、双份回复。
③ 安装包不带大模型默认说话走在线渠道，零下载；本地音色和翻唱按需再装。

1 装插件 必装

用本地目录安装 DSH

在 DSH 里选「本地目录安装」，指向你解压出来的项目文件夹，不要填 GitHub 地址。装完重启 DSH，左侧栏会出现「懂你的QQ大肥鱼」。

这一步不需要音频服务，也不需要开终端。升级也是同一个动作：重新选一次这个文件夹，然后重启。

2 让机器人号上线 必装

装 QQ 网关 QQ / 桌面端

  • macOS 用 NapCat：装在 QQ 里，扫码登录机器人号，控制台是 http://127.0.0.1:6099。
  • 在 NapCat 里开「正向 WebSocket」，端口本机推荐 6700（它默认可能是 3001，以实际监听的为准）。
  • QQ 更新会覆盖 NapCat 的注入文件，更新后重装一次 NapCat 即可。
  • Windows 用 SnowLuma 完整版（不是 lite），自己下载、自己点同意用户协议。
  • 解压到纯英文目录，例如 C:\qq-soul\snowluma，解压后目录里能直接看到 index.mjs。
  • 在它里面登录机器人号；控制台密码由插件自动生成和保存，你不用记。
在哪点：回面板「连接」页 →「本机服务（QQ / 网关 / 语音）」→「启动 QQ 与网关」。这一处就够了，不用再找第二个启动按钮。

3 连上并试运行 必装

确认是她本人在线 桌面端

  • 面板「安装中心」会显示五盏灯，前三盏（插件 / QQ 网关 / 音频服务）里前两盏必须亮。
  • 在「连接」页点「连接」或「接入机器人号」，插件会核对登录的是不是机器人号，不是就断开。
  • 先开着「试运行」聊两句：她照常思考，但只写日志、不真的发出去。确认没问题再关掉试运行。
到这里就能在 QQ 里说话了。下面的 4、5 是可选能力，不做也不影响聊天。

4 让她会说话 可选

先用在线的，想换本地音色再装 桌面端

默认走在线音色（零下载），只回文字也能用。要发语音条才需要本机的 9876 音频服务：

最简单：面板「概览」→「音频服务」卡片 →「启动服务」，然后把「启用音频服务」打开。

没起来时，在终端里跑（先 cd 到插件目录）：

cd "<插件目录>" && python3 -m services --servecd /d "<插件目录>" && python -m services --serve

起来后在「语音」页点一次试听。要换成本地音色（GPT-SoVITS / 千问 TTS 等），在「语音」页选渠道；不想折腾就保持在线。

5 让她会唱歌 可选 · 约 5–8 GB

翻唱（RVC）桌面端 · 翻唱

这是可选能力：不装也能聊天、也能发语音，只是唱不了。

  • Windows：面板「翻唱」→「一键安装」，约 8 GB。有 NVIDIA 独显会快很多，没有也能用 CPU 跑。
  • macOS：面板「翻唱」→「一键安装」，约 5 GB（不装 CUDA）。Apple 芯片会用 MPS 加速，没加速到的算子自动退回 CPU，慢一些但能跑。
  • 装完在「翻唱 → 音色模型」导入你有权使用的 .pth（zip / rar 也行）。
  • 「装到哪里」直接点面板里的位置按钮，不用手打路径；默认在你的用户目录下，不碰系统 Python。
  • 装到一半失败：展开「详细日志」把报错复制给 AI，已下好的部分不会重下。

6 跑一遍自检

该绿的绿了就能用 桌面端 / 运维大屏

面板「连接」页的「连接体检」，或运维大屏「引导与原理 → 依赖体检」。必装项看 service / gateway / tts，翻唱是 song（可选）。

有红的，把那一步的报错原文复制给 AI 就行。

? 卡住了？

DSH 每隔几分钟自己重启

多半是旧桥留下的守护进程在杀它。macOS 上检查 ~/Library/LaunchAgents/ 里有没有 com.merzlin.dsh-qq-supervisor.plist，有就移走。

面板显示「已就绪」，但 QQ 连不上

看网关端口有没有在听、插件有没有连上。面板「连接」页的「连接状态」会写清楚是没启动、没连上，还是登录的不是机器人号。

她一次回两条

NapCat 里还留着反向连 6700 的旧桥配置。删掉它，只保留正向 WebSocket。

翻唱安装失败，提示找不到 uv / ditto

这是安装器缺了系统工具。macOS 自带的 ditto、curl、tar 一般都在；uv 会自动下载到安装目录，失败时把「详细日志」整段复制给 AI。

网页大屏和桌面端看到的数不一样

两边读同一份配置，但分工不同：桌面端是唯一的写入口，网页只做日志、用量、作业进度、成品目录、模型库浏览。看到「去桌面端」就回面板找对应卡片。
