# 快速开始 · 详细版

> 只想 3 分钟跑通？看 [README 快速开始](../README.md#-快速开始)。
> 这篇写给愿意多花 10 分钟、想一次装明白的人：每一步都写清「为什么、怎么做、怎么确认好了」。

**装完前你能得到什么：**

- **必装三件套（约 3 分钟）**：插件 + QQ 网关 + 试运行。做完就能在 QQ 里跟她说话。
- **可选增强**：语音条、本地音色、翻唱、桌宠、生图。不装也能正常聊天。

**开始之前：**

| 你需要 | 说明 |
|---|---|
| 一台电脑 | macOS 或 Windows 都行；Linux 只要有 DSH 也能跑 |
| DeepSeek Harness（DSH） | 插件跑在它里面 |
| 一个 QQ 小号 | **必须是小号**——主号拿去当机器人，你自己就没法正常用了 |
| 一个 QQ 网关 | 让机器人号在线的程序，macOS 用 NapCat，Windows 用 SnowLuma / NapCat |

> ⚠️ **别同时装上游 Aurabot 插件。** 两者挂载 ID、配置目录完全相同，同时装会撞车、双份回复。装过的话先卸载。

---

## 第 1 步 · 装插件（必装）

### 用面板装（推荐，不用开终端）

1. 打开 DSH。
2. 找到插件管理里的「**从本地目录安装**」。
3. 选你解压出来的这个项目文件夹，**不要填 GitHub 地址**。
4. 装完重启 DSH。

左侧栏会出现「**懂你的QQ大肥鱼**」，点开就是面板。

### 用命令行装

```bash
dsh plugin --profile <profile> add "<插件目录>"
```

Windows 桌面版的 `dsh` 在安装目录里：

```powershell
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "<插件目录>"
```

> **为什么强调本地目录安装？** 本地目录是 `link:` 软链，你改的就是跑的那份；用 `github:` 地址装会变成「改仓库版、跑副本」，排查问题时容易对不上。

**怎么算好了：** DSH 重启后左侧栏出现「懂你的QQ大肥鱼」。

---

## 第 2 步 · 让机器人号上线（必装）

插件不自己登录 QQ，它连一个已经登录好的网关。网关用哪个看系统：

### macOS：NapCat

1. 按 [NapCat 官方文档](https://napneko.github.io/) 把 NapCat 装进 QQ。
2. 启动后打开它的控制台 `http://127.0.0.1:6099`，扫码登录**机器人小号**。
3. 在 NapCat 里开「**正向 WebSocket**」，记下端口。本机推荐 `6700`；NapCat 默认可能是 `3001`，以它实际监听的为准。
4. 回面板「连接」页 →「本机服务（QQ / 网关 / 语音）」→ 点「**启动 QQ 与网关**」。
5. 在「连接」页填 WebSocket 地址（例如 `ws://127.0.0.1:6700`），点「连接」。

> **注意：** QQ 更新会覆盖 NapCat 的注入文件（`loadNapCat.js`），更新后 NapCat 会失效，重装一次就好。
> 也支持 LLOneBot、Lagrange、Docker 里的 OneBot v11——只要是正向 WebSocket 都行。

### Windows：SnowLuma 或 NapCat

**先看看本机有没有已经装好的 NapCat。** 有就直接用 NapCat，最省事：

- 和 macOS 一样开「正向 WebSocket」（常见 `3001` / `6700`），把地址填进面板「连接」页。
- 不要再开它会反向连 `6700` 的旧配置，否则同一个号会被两个消费者抢答。

**没有就用 SnowLuma 完整版（不是 lite）：**

1. 去 [SnowLuma Releases](https://github.com/SnowLuma/SnowLuma/releases) 下载完整版。
2. 解压到**纯英文、不带空格**的目录，例如 `C:\qq-soul\snowluma`；解开后目录里能直接看到 `index.mjs`。
3. 启动 SnowLuma，**本人同意它的用户协议**（协议不允许别的程序替你自动部署和同意）。
4. 在里面登录机器人小号。
5. 回面板「连接」页 → 点「**启动 QQ 与网关**」。控制台密码由插件自动生成和保存，你不用记。

> SnowLuma 只有 Windows 版。macOS 上在面板里会默认帮你选 NapCat。

**怎么算好了：** 面板「安装中心」顶部的「QQ 网关」灯变绿；「连接」页显示登录的是你的机器人号。

---

## 第 3 步 · 试运行，确认她真的会说话（必装）

1. 面板右上角确认「试运行」是**开着**的——她会照常思考、把回复写进日志，但**不会真的发到 QQ**。
2. 用你的主号给小号发一句话。
3. 回面板「概览 → 日志」，看到她想了什么、准备回什么。
4. 没问题就把「试运行」关掉，正式上线。

**怎么算好了：** 关掉试运行后，QQ 里能收到她的回复。

到这里必装部分就结束了。下面是**可选增强**，按需装。

---

## 可选 1 · 语音条和本地音色

聊天用文字也能用。要发**语音条**，才需要本机的 `9876` 音频服务：

1. 面板「概览 → 音频服务」→ 点「**启动服务**」。
2. 把「**启用音频服务**」打开。
3. 面板「语音」页点一次「试听」。

服务没起来时，也可以在终端里跑（先 `cd` 到插件目录）：

```bash
# macOS / Linux
cd "<插件目录>" && python3 -m services --serve

# Windows
cd /d "<插件目录>" && python -m services --serve
```

先查依赖再启动：

```bash
python3 -m services --check-deps     # Windows 把 python3 换成 python
```

**默认走在线音色（edge-tts，零下载）。** 想要她用自己的声音，再在「语音」页换本地音色：

| 音色 | 怎么装 | 体积 |
|---|---|---|
| 在线 edge-tts | 默认，什么都不用做 | 零下载 |
| GPT-SoVITS | 自己起服务，面板填 HTTP 地址 | 视整合包 |
| 千问 3-TTS（MLX） | macOS：面板「声音」页选模型目录加载 | 几个 GB |
| 任意 HTTP TTS | 面板填地址，任何兼容接口都行 | 看你自己的实现 |
| CosyVoice / Breeze | 面板选渠道，Breeze 只填 key | 按渠道 |

**不需要独立显卡。** 有 NVIDIA 会快一些，没有也能跑，就是慢点。

## 可选 2 · 翻唱（用自己的声音唱歌）

翻唱是**可选能力**：不装也能聊天、也能发语音，只是唱不了。

1. 面板「翻唱」→ 点「**一键安装**」。
2. 「装到哪里」直接点面板里的位置按钮，**不用手打路径**。默认在你的用户目录下，不碰系统 Python。
3. 装完在「翻唱 → 音色模型」导入你有权使用的 `.pth`（zip / rar 也行）。

| 系统 | 体积 | 说明 |
|---|---|---|
| macOS | 约 **5 GB** | 装独立的 Python 环境，用 PyPI 的 CPU / MPS 版 PyTorch，**不装 CUDA**；Apple 芯片用 MPS 加速，没加速到的算子自动退回 CPU |
| Windows | 约 **8 GB** | 会装 CUDA 版 PyTorch 和人声分离的 GPU 依赖；**有 NVIDIA 独显会快很多，没显卡也能用 CPU 跑** |

一键安装会下载：Python 运行环境、Applio 推理脚本、人声分离 + 分离模型、ffmpeg、RVC 预训练权重。**已经下好的部分不会重下**，中途失败可以重试接着装。

**装到一半失败怎么办：** 展开「详细日志」，把报错整段复制给 AI；或者看 [install.html 的「卡住了」](install.html)。macOS 用系统自带的 `ditto` / `curl` / `tar` 解压和下载，不需要额外装工具。

## 可选 3 · 桌宠、生图

- **桌宠**：面板「桌宠」页装客户端，让她住在桌面上。
- **生图**：面板「生图」页接一个生图模型或你已有的服务。

这两个都不影响 QQ 聊天，随时可以装或关。

## 装完自检

面板「安装中心」顶部有五盏灯：

| 灯 | 绿了说明 | 必装？ |
|---|---|---|
| 插件 | 插件加载成功 | **是** |
| QQ 网关 | 机器人号已连上 | **是** |
| 音频服务 | `9876` 服务在跑 | 发语音条才需要 |
| 声音 | 会用某种音色说话 | 是（在线音色也算） |
| 翻唱 | RVC 环境完整 | 可选 |

更细一点：面板「连接」页 →「连接体检」，或运行看盘「安装与体检」（`http://127.0.0.1:9876/panel#guide`），看 `service / deps / gateway / tts / song` 五步。必装项全绿就能用；有红的，把那一步的报错原文复制给 AI。

## 升级、卸载、换电脑

### 升级

重新用本地目录安装一次（还是那个文件夹），然后重启 DSH。**设置、人格、记忆、表情、你自己写的模块都会保留。**

### 卸载

在 DSH 的插件管理里移除本插件。数据目录不会自动删，想彻底清掉再手动删：

```text
macOS / Linux:  ~/.dsh/plugins-data/aurabot/
                ~/.dsh/plugins-data/qqsoul/
Windows:        %USERPROFILE%\.dsh\plugins-data\aurabot\
                %USERPROFILE%\.dsh\plugins-data\qqsoul\
```

### 换电脑

面板「系统 → 备份」把配置、记忆、人设、表情、自己写的模块和 QQ 会话打成一个 zip。新电脑装好插件后把 zip 拖进去，重启即恢复；市场模块会自动重新下载。

## 常见问题

**DSH 每隔几分钟自己重启？**
多半是旧桥留下的守护进程在杀它。macOS 上检查 `~/Library/LaunchAgents/` 里有没有 `com.merzlin.dsh-qq-supervisor.plist`，有就移走。

**面板显示「已就绪」，但 QQ 连不上？**
先看面板「安装中心」的网关灯，再看「连接」页写的具体原因：没启动、没连上，还是登录的不是机器人号。

**她一次回两条？**
NapCat 里还留着反向连 `6700` 的旧桥配置。删掉它，只保留正向 WebSocket。

**翻唱安装失败，提示找不到 `uv` / `ditto`？**
`uv` 会自动下载到安装目录；macOS 的 `ditto`、`curl`、`tar` 是系统自带的。还是失败就把「详细日志」整段发给 AI。

**点歌后她说「做好了就发我」，然后没动静？**
现在搜不到 / 要会员 / 缺模型都会在聊天里明说。如果还是沉默，去翻唱页看作业日志，把报错发给 AI；也可以先换一首，或在「音乐源」里加一个源。

**服务还没起来，安装说明打不开？**
双击 `docs/install.html`。它不依赖服务，浏览器直接打开就能看。

**不想一步步看，想让 AI 带着装？**
把 [INSTALL-WITH-AI.md](INSTALL-WITH-AI.md) 里那段提示词整段复制给 DSH 里的 AI。
