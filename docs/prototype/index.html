工具与技能

两类各有开关，前台一个统一管理平台。按确定性分类，不是按文件格式：代码工具是自动机器，Markdown Skill 是菜谱。

代码工具 固定流程

只常驻一行 description；结果回来才进上下文；零额外 token。

作用域：只挂肥鱼自己的会话，不注册成 DSH 全局技能。

知识技能 Markdown / SOP

索引常驻、命中才加载正文；需要模型读说明再决策，走偏与多轮风险由加载器兜。

人格补充设定 Markdown Skill 加载器 · P2 之后

注意：Skill 费的不是「Markdown 这种形式」，而是全文常驻 prompt；技能多了涨的是工具清单膨胀。

意图 / 执行 / 可观测

LLM 只管意图：要不要做、做什么

面板负责状态：SSE / 确定性通道，不让模型用自然语言轮询烧 token
产品差别：「模型自己瞎猜哪里错了」vs「面板显示第 3 步失败、点这里加载模型」——这是两款产品。
