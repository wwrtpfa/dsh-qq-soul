# 她为什么主动找你说话

没人理她时，她不会马上凑上来：先等够时间、过完几道闸门，再从聊天和记忆里挑一件想跟你说的事，写一句话发到你（或白名单里的人）的 QQ 私聊。不是复读问候，也不会在群里凭空喊你。发不发、发几次，由总开关、试运行、醒着时间、每日上限决定。注意默认是「总开关关、试运行开」，刚装好一句都不真发，要主人自己放开。

## 一句话流程

1. 定时：两个模块各注册 60 秒一次的 `tick`，是自动触发的唯一定时源；没有「一闲就发」，靠到点加上你已一阵子没私聊。
2. 过闸门：总开关、试运行、禁言、醒着时段、安静时段、今日次数、间隔、主人空闲够不够，不过就改约下次。
3. 二选一：默认「主动搭话」从预设由头（分享小事、接上次话题、想起你的事、按时问候）随机挑；可选「目的引擎」默认关，是替代引擎，开启后旧搭话会主动让路，面板仍建议别两套同开。
4. 挑目的：收最近两天私聊与群聊流水、长期记忆、人格卡和「心里惦记的事」；算九维驱动（想玩、想陪、想分享），你沉默越久「想陪」越高，反复看到的话题推高对应需求；生成带置信度、风险的目标假设与候选，去重轮换后加权随机挑一个。素材太少整轮跳过。朋友只看与对方有关的素材。
5. 生成：拼提示词让模型直接写那句；她可回「沉默」或留空，算决定不说，不硬发。
6. 落地：默认投主人私聊；改成桌宠且在线就走桌面气泡，离线按开关回落 QQ 或静默，专注模式开着则静默。铁律一轮只发一处，绝不两头都发，结果不确定也不重发。
7. 回执：真发出才结算心情与次数；投递带「系统提醒，不是主人说的话」前缀，让心情判定知道她是主动开口。

## 常见疑问 / 太吵或太安静怎么办

1. 太吵：调小「每天最多」、拉长「两次之间隔」、调大「多久没聊才找你」、关「追问」；最省事关掉主动搭话总开关。「现在就让她来找我」只手动一次，不改节奏。
2. 太安静：确认右上角总开关已开、试运行已关（默认一关一开），再看今日次数是否到顶、是否在醒着时间外、是否在私聊里让她闭嘴。
3. 想先看内容：用「预览这一轮（零副作用）」，只收素材拼提示词，不写状态、不生成、不投递；「立即试一次」才真跑一轮并占次数。
4. 群里会主动找我吗：不会，主动搭话只落 `private:` 私聊。群聊插话是另一套，有人说话才按相关度与概率接一句，受冷却、每小时上限、静默时段管，心情好更爱插。
5. 节奏预设与谷时能让她少来吗：预设（保守/默认/活跃）目前只保存回显，真正管间隔的是「两次之间隔」与「每天最多」；谷时省钱只把峰时心情模型判断推迟，不影响搭话到点。
