# 装「懂你的QQ大肥鱼」——复制这段给 AI，让它带你装

> 你不用看懂下面这些。把**整段**复制，粘给 DeepSeek Harness（DSH）里的 AI，它就会一步一步问你、帮你做。
> 你只需要：会复制粘贴、会点「同意」、知道自己的 QQ 号。
>
> 不想让 AI 带着装、或者还没装服务？直接双击同目录的 **docs/install.html**（浏览器打开即可）。
> 那是一份离线安装引导，不依赖 127.0.0.1:9876；服务起来后也可以访问 `/install-guide`。
>
> 更详细的说明在 **docs/quickstart.md**。

## 复制这一段 👇

```
我要在我的电脑上装一个叫「懂你的QQ大肥鱼」的 DSH 插件。
我不懂技术，请你一步一步带我装，每次只让我做一件事，做完等我说「好了」再继续。

我的情况：
- 系统：（macOS / Windows，二选一）
- 插件目录：（贴你放这个插件的文件夹路径）
- 机器人 QQ 号（小号）：（填）
- 我自己的 QQ 号（主人号）：（填）

请按这个顺序带我（前三步是必装，做完就能在 QQ 里说话）：
1. 装插件：用本地目录安装（不要用 github 地址），装完重启 DSH。
2. 重启后让我在 DSH 左侧栏找到「懂你的QQ大肥鱼」，打开面板 →「安装中心」。
3. 装 QQ 网关：macOS 用 NapCat（扫码登录，开「正向 WebSocket」，本机推荐 6700，以它实际监听的为准）；
   Windows 用 SnowLuma 完整版（不是 lite），解压到纯英文目录（例如 C:\qq-soul\snowluma），在里面登录机器人号。
   然后回面板「连接」页 →「本机服务（QQ / 网关 / 语音）」→ 点一次「启动 QQ 与网关」，
   核对登录的是机器人号；先开着「试运行」聊两句，确认没问题再上线。

下面三步是可选的，我不问就先别装：
4. 要发语音条时再起音频服务：面板「概览 → 音频服务」点「启动服务」，然后打开「启用音频服务」，
   在「语音」页点一次试听。默认走在线音色（零下载），想换本地音色再装。
5. 翻唱（RVC）：面板「翻唱」→「一键安装」。macOS 约 5 GB，Windows 约 8 GB；
   装到哪直接点面板里的位置按钮，别让我手打路径。装完在「音色模型」导入我有权使用的 .pth。
6. 跑一遍自检（面板「连接体检」或运行看盘「安装与体检」）：service / deps / gateway / tts 这几项必装，
   song 是翻唱可选。有红的，把那一步的报错原文贴给你。

每一步做完，请用一句话告诉我「刚才做了什么、现在是什么状态、下一步要干嘛」。
遇到要我在电脑上手动点的（同意协议、选文件/选目录），直接告诉我去点哪里，别让我手打路径。
```

## 装之前，先确认这 3 件事

| # | 事 | 为什么 |
|---|---|---|
| 1 | **机器人号必须是小号** | 主号拿来当机器人，你自己就没法正常用了 |
| 2 | **别装上游 Aurabot** | 两者挂载 ID、配置目录完全相同，会撞车、双份回复；没装就什么都不用做 |
| 3 | **安装包不带任何大模型** | 默认说话走在线渠道（零下载）；要本地音色/唱歌才按需下 |

---

## 必装 vs 可选

| 能力 | 要不要装 | 体积 | 不装会怎样 |
|---|---|---|---|
| 插件 + QQ 网关 | **必装** | 网关几十 MB | 用不了 |
| 在线音色（文字 / 语音条） | 必装里最省事 | 零下载 | 只能发文字 |
| 本机音频服务（`9876`） | 发语音条才需要 | 几百 MB | 没有语音条、翻唱 |
| 本地音色（TTS） | 可选 | 约 300 MB 起 | 继续用在线音色 |
| 翻唱（RVC / Applio） | 可选 | macOS 约 5 GB / Windows 约 8 GB | 唱不了歌 |
| 桌宠 / 生图 | 可选 | 视渠道 | 没有对应能力 |

## 两个平台不一样的地方

### macOS

- QQ 网关用 **NapCat**，装在 QQ 里；扫码登录走 NapCat 自己的 `http://127.0.0.1:6099`
- 翻唱一键安装约 **5 GB**：装一套独立的 Python 环境（PyPI 的 CPU / MPS 版 PyTorch，**不装 CUDA**），
  位置默认在用户目录下的 `Aurabot/rvc`，不碰系统 Python
- Apple 芯片用 MPS 加速，没加速到的算子自动退回 CPU；**不需要独立显卡**
- **注意**：QQ 更新会覆盖 NapCat 的注入文件（`loadNapCat.js`），更新后 NapCat 会失效，要重装一次

### Windows

QQ 网关二选一，**本机已经装了 NapCat 就用 NapCat，最省事**：

- **NapCat**（推荐，如果已经装好）：和 macOS 一样开「正向 WebSocket」，端口填它实际监听的（常见 3001 / 6700）
- **SnowLuma 完整版**（不是 lite）：自己下载解压，解压到**纯英文目录**，例如 `C:\qq-soul\snowluma`；协议不允许程序替你自动部署，得你自己下载、自己点同意

其余和 macOS 不同的地方：

- 起音频服务用 `python`（不是 `python3`）：`cd "<插件目录>"; python -m services --serve`
- 音频服务的配置、模型和翻唱缓存另放一处：`%USERPROFILE%\.dsh\plugins-data\qqsoul\service\`
- 翻唱一键安装约 **8 GB**：会装 CUDA 版 PyTorch 和人声分离的 GPU 依赖；**有 NVIDIA 独显会快很多，没有也能用 CPU 跑**
- **千问 3-TTS**：Windows 连本机 `9883` 常驻服务，不需要 MLX，也不用选模型目录

两个系统都一样：**路径都从面板点按钮选，不用手打。**

## 装完怎么确认好了

先看面板「安装中心」顶部的五盏灯：**插件 / QQ 网关 / 音频服务 / 声音 / 翻唱**。
前两盏必须亮，后三盏是可选能力的进度。

要更细一点，桌面端「连接」页点「连接体检」，或打开 `http://127.0.0.1:9876/panel#guide` 的「安装与体检」（依赖体检 + 五步自检都收在这一页），看五步：

| 步 | 绿了说明 | 必装？ |
|---|---|---|
| service | 音频服务起来了 | 发语音条才需要 |
| deps | 依赖都齐了 | 同上 |
| gateway | QQ 连上了 | **是** |
| tts | 能说话了 | 是 |
| song | 能唱歌了 | 可选 |

**必装项全绿 = 可以用了。** 有红的，把那一步的报错原文复制给 AI。

## 常见问题

**Q：DSH 每隔几分钟自己重启？**
A：多半是旧桥留下的守护进程在杀它。macOS 上检查 `~/Library/LaunchAgents/` 里有没有 `com.merzlin.dsh-qq-supervisor.plist`，有就移走。

**Q：面板显示「已就绪」，但 QQ 连不上？**
A：看运行看盘右上角是不是「演示数据」。演示数据全是示例、不是本机真实状态，要点「连接设置」连上 service 才是真的。

**Q：她一次回两条？**
A：NapCat 里还留着反向连 6700 的旧桥配置。删掉它，只保留正向 WebSocket。

**Q：翻唱安装失败，提示找不到 `uv` / `ditto`？**
A：macOS 自带 `ditto`、`curl`、`tar`，一般都在；`uv` 会自动下载到安装目录。失败时展开「详细日志」，整段复制给 AI。已经下好的部分不会重下。

**Q：点歌之后她说「做好了就发我」，然后没动静了？**
A：旧版本失败时确实没回话。现在搜不到 / 要会员 / 缺模型都会在聊天里明说；如果还是沉默，去翻唱页看作业日志，并把报错发给 AI。也可以先换一首，或在「音乐源」里加一个源。

**Q：插件面板和运行看盘数据不一样？**
A：两边读同一份配置，但分工不同：**桌面面板是唯一的写入口**（人格、记忆、QQ 连接、音频服务开关、语音、音色、翻唱策略、音乐源、启停、点歌）；**运行看盘只读**（状态灯、安装与体检、翻唱曲库、声音现状、动态与日志、资源与目录）。看到「去桌面端」就回面板找对应卡片。

**Q：服务还没起来，安装说明打不开？**
A：双击 `docs/install.html`。`/panel` 和 `/install-guide` 由服务托管，服务没起来时确实打不开，所以安装引导另有一份纯静态页；桌面端「概览 → 音频服务」里也内置了同样的步骤。
