# 装「懂你的QQ大肥鱼」——复制这段给 AI，让它带你装

> 你不用看懂下面这些。把**整段**复制，粘给 DeepSeek Harness（DSH）里的 AI，它就会一步一步问你、帮你做。
> 你只需要：会复制粘贴、会点「同意」、知道自己的 QQ 号。
>
> 不想让 AI 带着装、或者还没装服务？直接双击同目录的 **docs/install.html**（浏览器打开即可）。
> 那是一份离线安装引导，不依赖 127.0.0.1:9876；服务起来后也可以访问 `/install-guide`。

---

## 复制这一段 👇

```
我要在我的电脑上装一个叫「懂你的QQ大肥鱼」的 DSH 插件。
我不懂技术，请你一步一步带我装，每次只让我做一件事，做完等我说「好了」再继续。

我的情况：
- 系统：（macOS / Windows，二选一）
- 插件目录：（贴你放这个插件的文件夹路径）
- 机器人 QQ 号（小号）：（填）
- 我自己的 QQ 号（主人号）：（填）

请按这个顺序带我（就五步）：
1. 装插件：用本地目录安装（不要用 github 地址），装完重启 DSH。
2. 重启后让我在 DSH 左侧栏找到「懂你的QQ大肥鱼」，打开面板。
   安装说明在 docs/install.html，双击就能看，不需要音频服务先起来。
3. 装 QQ 网关（macOS 用 NapCat，Windows 用 SnowLuma 完整版），
   关键是开「正向 WebSocket」：本机推荐 6700，NapCat 自己默认可能是 3001，填它实际监听的端口；
   然后回桌面端「连接」页，在「本机服务（QQ / 网关 / 语音）」卡片点一次「启动 QQ 与网关」。
4. 起音频服务：macOS / Linux 用 `cd "<插件目录>" && python3 -m services --serve`，
   Windows 用 `cd "<插件目录>"; python -m services --serve`；也可以在桌面端「概览」点「启动服务」，
   然后打开「启用音频服务」。接着在「语音」页试听一句、在「音乐源」点「测试搜索」搜一首歌名。
5. 跑一遍自检（桌面端「连接体检」或运维大屏「依赖体检」），看 service / deps / gateway / tts / song 五步，
   全绿就上线；说话渠道先用在线的零下载跑通，要本地音色再在「语音」页切换。

每一步做完，请用一句话告诉我「刚才做了什么、现在是什么状态、下一步要干嘛」。
遇到要我在电脑上手动点的（同意协议、选文件/选目录），直接告诉我去点哪里，别让我手打路径。
```

## 装之前，先确认这 3 件事

| # | 事 | 为什么 |
|---|---|---|
| 1 | **机器人号必须是小号** | 主号拿来当机器人，你自己就没法正常用了 |
| 2 | **别装上游 Aurabot** | 两者挂载 ID、配置目录完全相同，会撞车、双份回复；没装就什么都不用做 |
| 3 | **安装包不带任何大模型** | 默认说话走微软在线（零下载）；要本地音色/唱歌才按需下 |

## 两个平台不一样的地方

### macOS

- QQ 网关用 **NapCat**，装在 QQ 里；扫码登录走 NapCat 自己的 `http://127.0.0.1:6099`
- 音频引擎复用 `~/tools/applio`（如果已经装了）
- GPT-SoVITS 整包如果已经在 `~/tools/GPT-SoVITS`，模型页会自动认出来，不用再下一份
- **ffmpeg**：`brew install ffmpeg`
- **千问 3-TTS**：走 MLX 本地模型，在「声音」页的「模型目录」里选目录加载
- **不需要独立显卡**：Apple 芯片直接跑
- **注意**：QQ 更新会覆盖 NapCat 的注入文件（`loadNapCat.js`），更新后 NapCat 就失效了，要重装一次

### Windows

QQ 网关二选一，**本机已经装了 NapCat 就用 NapCat，最省事**：

- **NapCat**（推荐，如果已经装好）：和 macOS 一样开「正向 WebSocket」，端口填它实际监听的（常见 3001 / 6700）
- **SnowLuma 完整版**（不是 lite）：自己下载解压，解压到**纯英文目录**，例如 `C:\qq-soul\snowluma`；协议不允许程序替你自动部署，得你自己下载、自己点同意

其余和 macOS 不同的地方：

- 起音频服务用 `python`（不是 `python3`）：`cd "<插件目录>"; python -m services --serve`
  - 装在 `D:\Python312` 或 `C:\Python312` 会被自动找到；装别处就在设置里指一下 `python.exe`
- 音频服务的配置、模型和翻唱缓存另放一处：`%USERPROFILE%\.dsh\plugins-data\qqsoul\service\`
- **ffmpeg**：下载 `ffmpeg.exe`，把**完整路径**填进设置（不用加进 PATH）
- **换声（RVC）**：可以用技能包里的快速 RVC（默认 `D:/tools/rvc`），也可以装 Applio
- **千问 3-TTS**：Windows 连本机 `9883` 常驻服务，不需要 MLX，也不用选模型目录
- **不需要独立显卡**：有 NVIDIA 会快一些，没有也能跑（走 CPU 会慢）

## 装完怎么确认好了

桌面端「连接」页点「连接体检」，或打开 `http://127.0.0.1:9876/panel` 的「依赖体检」，看五步：

| 步 | 绿了说明 |
|---|---|
| service | 音频服务起来了 |
| deps | 依赖都齐了 |
| gateway | QQ 连上了 |
| tts | 能说话了 |
| song | 能唱歌了 |

**五步全绿 = 可以用了。** 有红的，把那一步的报错原文复制给 AI。

## 常见问题

**Q：DSH 每隔几分钟自己重启？**
A：多半是旧桥留下的守护进程在杀它。macOS 上检查 `~/Library/LaunchAgents/` 里有没有 `com.merzlin.dsh-qq-supervisor.plist`，有就移走。

**Q：面板显示「已就绪」，但 QQ 连不上？**
A：看大屏右上角是不是「演示模式」。演示模式的数据全是假的，要点「连接 service」才是真的。

**Q：她一次回两条？**
A：NapCat 里还留着反向连 6700 的旧桥配置。删掉它，只保留正向 WebSocket。

**Q：点歌之后她说「做好了就发我」，然后没动静了？**
A：旧版本失败时确实没回话。现在搜不到 / 要会员 / 缺模型都会在聊天里明说；如果还是沉默，去翻唱页看作业日志，并把报错发给 AI。也可以先换一首，或在「音乐源」里加一个源。

**Q：插件面板和运维大屏数据不一样？**
A：两边读同一份配置，但分工不同：**桌面面板是唯一的写入口**（人格、记忆、QQ 连接、音频服务开关、语音、音色、翻唱策略、音乐源、启停、点歌）；**运维大屏只读看盘**（日志、用量、作业进度、成品目录、模型库浏览、原理介绍）。大屏里的写按钮都已收起，看到「配置与操作在桌面端」就回面板找对应卡片。

**Q：服务还没起来，安装说明打不开？**
A：双击 `docs/install.html`。`/panel` 和 `/install-guide` 由服务托管，服务没起来时确实打不开，所以安装引导另有一份纯静态页；桌面端「概览 → 音频服务」里也内置了同样的步骤。
